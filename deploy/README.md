# 🍶 Plastic Bottle Waste Detection

Deteksi botol plastik menggunakan model YOLOv8n yang telah dilatih pada dataset botol plastik.

Fitur:
- **Upload Foto** — Upload gambar untuk deteksi botol plastik
- **Kamera** — Ambil foto langsung dari webcam untuk deteksi real-time

Model dilatih dengan YOLOv8n (nano) untuk kecepatan inferensi yang optimal dengan akurasi yang memadai.
